# Lab Notes

I use this repository to keep my lab notes, exercises, and code examples in one place. The material is organized by course.

## Courses

- [Operating Systems](operating%20systems/) contains C exercises for Linux on process creation, POSIX threads, shared memory, and synchronization. It includes producer–consumer examples with single-slot and circular buffers, plus a small shell that launches commands. Some exercises also include notes, Makefiles, and lab materials. The course README describes each folder and shows how to build a first example.
- [Electrical and Electronic Measurements](electrical%20and%20electronic%20measurements/) contains five STM32CubeIDE exercises on GPIO outputs, button inputs, and hardware timers. The course README lists the projects and explains how to import them.
- [Advanced Computer Programming](advanced%20computer%20programming/) is set aside for programming notes and exercises from that course.
